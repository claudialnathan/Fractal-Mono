02

Distinguishing construction

The family stays strictly monospaced at every width while making frequently confused forms immediately distinct. These are the default drawings, not alternates staged for the specimen.

O o 0

Dotted counters

Capital and lowercase O use centre dots by default. The zero keeps its wider dot, while lowercase o scales the same contour to 82%.

1 I l

Disambiguation

Narrow one, serifed capital I, and flag-and-foot lowercase l.

K k r

Style anchors

Plain joined K, open lowercase k, and Fractal’s rising r shoulder.

t k w

Independent drawings

Short-hooked t, open k, and angular-pinched w redrawn for Fractal’s cell.

/\ () {}

Measured symbols

Tall but line-fitting slashes, compact brackets, and narrower braces.

    Complete archive

    Download ZIP
    macOS
    1. Remove earlier Fractal Mono installations.
    2. Open FractalMono-Variable.ttf in Font Book.
    3. Choose Install, then restart applications that cached the old face.
    Windows
    1. Remove earlier Fractal Mono installations in Font settings.
    2. Right-click the variable TTF and choose Install for all users.
    3. Restart applications that were open during installation.
    Linux
    1. Copy the variable TTF to ~/.local/share/fonts/.
    2. Run fc-cache -f.
    3. Restart applications that were open during installation.

    Authorship, licence, and scope

    Fractal Mono is designed by Claudia Nathan. Its metrics, fitting, letterforms, features, and specimens form one coherent family.

    Designer

    Claudia Nathan designed Fractal Mono for code, interfaces, technical writing, and graphic use.

    Signature forms

    R, r, K, J/j, t, and w anchor the family. Dotted O/o/0, compact symbols, and its strict per-width cells complete Fractal Mono’s visual language.

    See the construction

    Coding behavior

    All programming sequences stay literal by default. Optional joined drawings remain available through dlig without changing cursor cells.

    Release 1.000

    Weight, width, and optical-size masters, redesigned signature forms, and clean square-dot punctuation in one variable family.

    Full project notes
    Included now

    Roman upright; weight 100–800; width 85–115; optical size 9–72; 9 named weight instances; Latin, Cyrillic, Greek, symbols, code alternates; 38 OpenType tags.

    Deliberate defaults

    Dotted O/o/0; programming ligatures off; tabular monospacing at every width; unhinted transformed outlines; modern grayscale smoothing.

    Not in 1.000

    Italic or slant axis; purpose-built Windows hinting; native editorial review for every detected language.

    Release validation

    30 files parsed; 315 combined-axis instances, cell widths, features, repeat guards, metrics, hashes, browser rendering, and protected outlines checked.
